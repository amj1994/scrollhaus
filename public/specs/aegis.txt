AEGIS OPS — Hero Section — complete build spec

A finished, single-file-hero build supplied ready-made: an enterprise
security-systems hero over a full-bleed autoplay-loop server-room video
background, a two-tone wordmark (white + mint-green accent), a dual-CTA
row (filled + outline), and a trust-signal line ("Austin, TX. 18 systems
deployed.").

Video: originally streamed from Gumlet at raw capture bitrate (25.3Mbps,
1080p, with an unused silent audio track) — extremely wasteful for a muted
background loop. Stripped audio, re-encoded (crf 22, dense forced keyframe
interval -g 6 -keyint_min 6 -sc_threshold 0) and self-hosted at
assets/video/aegis-hero.mp4 instead — a large cut, no dependency on an
external account staying active.

Motion: Lenis smooth scroll wired in (the page itself is a single fixed
viewport, so there's nothing to scroll, but every showcase in this library
ships Lenis by default).

Stack: Vite + React 18 + TypeScript + Tailwind CSS.

## Setup
`npm install`, then `npm run build`. Serve the built `dist/` (or `npm run dev`
for local iteration). The hero video must be present at
`assets/video/aegis-hero.mp4` relative to the served root.

### src/App.tsx
```tsx
import { useEffect } from 'react'
import Lenis from 'lenis'
import Navbar from './components/Navbar'
import HeroSection from './components/HeroSection'

function useLenis() {
  useEffect(() => {
    if (matchMedia('(prefers-reduced-motion: reduce)').matches) return
    const lenis = new Lenis({ duration: 1.0, easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)) })
    ;(window as unknown as { __lenis: Lenis }).__lenis = lenis
    let raf = 0
    function tick(time: number) {
      lenis.raf(time)
      raf = requestAnimationFrame(tick)
    }
    raf = requestAnimationFrame(tick)
    return () => {
      cancelAnimationFrame(raf)
      lenis.destroy()
    }
  }, [])
}

export default function App() {
  useLenis()
  return (
    <div className="bg-hero-bg min-h-screen font-sora antialiased">
      <Navbar />
      <HeroSection />
    </div>
  )
}
```
