Pyra — Fire-Forged Jewelry — complete build spec

Original design built around three Higgsfield-generated phoenix/ring image concepts and a generated hero video, per explicit user direction to vary the assets and design the page from scratch.

Stack: Vite + React 19 + TypeScript + Tailwind CSS v4 (via @tailwindcss/vite).
Dependencies: framer-motion@^11.18.2, lenis@^1.1.20, react@^18.3.1, react-dom@^18.3.1.
Dev dependencies: @tailwindcss/vite@^4.2.1, @types/react@^18.3.12, @types/react-dom@^18.3.1, @vitejs/plugin-react@^4.3.4, tailwindcss@^4.2.1, typescript@^5.8.0, vite@^7.0.0.

## Setup
1. `npm create vite@latest . -- --template react-ts`
2. Install the exact dependencies listed above (`npm install framer-motion@11.18.2 lenis@1.1.20 react@18.3.1 react-dom@18.3.1` plus dev deps `npm install -D @tailwindcss/vite@4.2.1 @types/react@18.3.12 @types/react-dom@18.3.1 @vitejs/plugin-react@4.3.4 tailwindcss@4.2.1 typescript@5.8.0 vite@7.0.0`).
3. Add a `"@/*": ["./src/*"]` path alias in tsconfig.json and vite.config.ts (resolve.alias), and add the `@tailwindcss/vite` plugin to vite.config.ts.
4. Replace the generated files below with the exact contents given — every file, verbatim.

### src/lib/useLenis.ts
```tsx
import { useEffect } from "react";
import Lenis from "lenis";

export function useLenis() {
  useEffect(() => {
    const lenis = new Lenis({
      duration: 1.2,
      easing: (t: number) => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
      smoothWheel: true,
    });

    // Exposed so capture/QA tooling can drive scroll directly via
    // lenis.scrollTo(pos, { immediate: true }) instead of synthetic wheel
    // events, which double up with Lenis's own easing and overshoot.
    (window as unknown as { __lenis?: Lenis }).__lenis = lenis;

    function raf(time: number) {
      lenis.raf(time);
      frame = requestAnimationFrame(raf);
    }
    let frame = requestAnimationFrame(raf);

    return () => {
      cancelAnimationFrame(frame);
      lenis.destroy();
      delete (window as unknown as { __lenis?: Lenis }).__lenis;
    };
  }, []);
}
```
