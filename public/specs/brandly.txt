Brandly — complete build spec

Recreation of a pasted 'Brandly' single-viewport brand-agency hero spec. The spec's own hero video URL pointed to another party's Higgsfield account, so it's an original Higgsfield-generated loop instead: cream and black ink pooling and flowing across an off-white surface, matching the page's own cream/black palette so the overlaid black text stays readable throughout.

Stack: Vite + React 19 + TypeScript + Tailwind CSS v3 (default config, via postcss).
Dependencies: lucide-react@^0.475.0, react@^19.0.0, react-dom@^19.0.0.
Dev dependencies: @types/react@^19.0.10, @types/react-dom@^19.0.4, @vitejs/plugin-react@^4.3.4, autoprefixer@^10.4.20, postcss@^8.4.49, tailwindcss@^3.4.15, typescript@^5.8.0, vite@^7.0.0.

## Setup
1. `npm create vite@latest . -- --template react-ts`
2. Install the exact dependencies listed above (`npm install lucide-react@0.475.0 react@19.0.0 react-dom@19.0.0` plus dev deps `npm install -D @types/react@19.0.10 @types/react-dom@19.0.4 @vitejs/plugin-react@4.3.4 autoprefixer@10.4.20 postcss@8.4.49 tailwindcss@3.4.15 typescript@5.8.0 vite@7.0.0`).
3. Run `npx tailwindcss init -p` to create tailwind.config.js and postcss.config.js (default config, content globs covering index.html and src/**/*.{js,ts,jsx,tsx}).
4. Replace the generated files below with the exact contents given — every file, verbatim.
