02

How to target an element

Every snippet needs to know what to style. You give the element an ID.

  1. Click the element, row or section
  2. Open the settings panel on the right
  3. Find Advanced → ID
  4. Type a name like hero-image
  • Lowercase, hyphens, never start with a number
  • IDs use # — classes use .
  • GHL wraps elements in extra divs. If #id alone fails, try #id img or #id a
03

Set your variables once

Paste this into Funnel Settings → Custom CSS before anything else. Every snippet below uses it.

Site CSS 
:root {
  --brand:      #FF6A00;
  --brand-dark: #D45400;
  --ink:        #0B0A0C;
  --radius:     14px;
  --ease:       cubic-bezier(.22,1,.36,1);
  --speed:      .35s;
}

Change the brand colour once at the top, and the whole site updates.

04

When it doesn't work

Nine times out of ten it's one of these.

  • You're looking at the editor. Click Preview — custom code doesn't render in the builder
  • Browser cache. Hard refresh: Cmd/Ctrl + Shift + R
  • Wrong ID. Right-click the element → Inspect, and check the ID actually matches
  • GHL's style wins. Add !important to that one property — sparingly
  • Script in the CSS box. Anything with <script> must be a code element
  • Sticky not sticking. A parent has overflow:hidden — that silently kills it

Scroll Reveal

MediumCSS + Code element
Live — scroll this into view
Elements fade up as they enter
Each one slightly delayed
Fires once, then stops

Where it goes — two parts

  1. Add class reveal to each element you want animated
  2. CSS below → Page Settings → Custom CSS
  3. Script below → code element at the bottom of the page
1 · Page CSS 
.reveal {
  opacity: 0;
  transform: translateY(28px);
  transition: opacity .7s var(--ease),
              transform .7s var(--ease);
}
.reveal.visible { opacity: 1; transform: none; }

/* stagger a row */
.reveal:nth-child(2) { transition-delay: .12s; }
.reveal:nth-child(3) { transition-delay: .24s; }

@media (prefers-reduced-motion: reduce) {
  .reveal { opacity: 1; transform: none; }
}
2 · Code element 
<script>
const io = new IntersectionObserver((entries) => {
  entries.forEach(e => {
    if (e.isIntersecting) {
      e.target.classList.add('visible');
      io.unobserve(e.target);
    }
  });
}, { threshold: 0.15 });

document.querySelectorAll('.reveal').forEach(el => io.observe(el));
</script>

Customise

  • Slide from the left — swap translateY(28px) for translateX(-28px)
  • Trigger earlier — lower threshold to 0.05
  • Repeat every time — delete the io.unobserve line

3D Tilt on Hover

AdvancedCode element
Live — move your cursor over it
Tilt Me

Rotates toward the cursor.

Where it goes

  1. Add class tilt to any element
  2. Add a code element at the bottom of the page
  3. Paste below
Code element 
<style>
.tilt{transition:transform .25s cubic-bezier(.22,1,.36,1);
  transform-style:preserve-3d;will-change:transform}
@media (hover:none){ .tilt{transform:none !important} }
</style>

<script>
document.querySelectorAll('.tilt').forEach(card => {
  card.addEventListener('mousemove', e => {
    const r = card.getBoundingClientRect();
    const x = (e.clientX - r.left) / r.width  - .5;
    const y = (e.clientY - r.top)  / r.height - .5;
    card.style.transform =
      `perspective(900px) rotateY(${x*12}deg) rotateX(${-y*12}deg) scale(1.03)`;
  });
  card.addEventListener('mouseleave', () => {
    card.style.transform = 'perspective(900px) rotateY(0) rotateX(0) scale(1)';
  });
});
</script>

Customise

  • Tilt strength — change both 12 values. 6 is subtle, 20 is dramatic
  • The @media (hover:none) block disables it on touch — keep it

Animated Counters

MediumCode element

0Projects

Where it goes

  1. Add a code element where you want the stats

  3. Edit the data-to numbers
Code element 
<div class="stats">
  <div><span class="count" data-to="127">0</span><small>Projects</small></div>
  <div><span class="count" data-to="98" data-suffix="%">0</span><small>Retention</small></div>
</div>

<style>
.stats{display:flex;gap:48px;flex-wrap:wrap}
.stats > div{text-align:center}
.count{font-size:clamp(38px,6vw,64px);font-weight:800;
  line-height:1;display:block;color:var(--brand)}
.stats small{display:block;margin-top:8px;font-size:12px;
  letter-spacing:.1em;text-transform:uppercase;opacity:.6}
</style>

<script>
const run = el => {
  const to = +el.dataset.to, sfx = el.dataset.suffix || '';
  const dur = 1700, t0 = performance.now();
  const tick = t => {
    const p = Math.min((t - t0) / dur, 1);
    const eased = 1 - Math.pow(1 - p, 3);
    el.textContent = Math.round(to * eased) + sfx;
    if (p < 1) requestAnimationFrame(tick);
  };
  requestAnimationFrame(tick);
};

const io = new IntersectionObserver(es => {
  es.forEach(e => {
    if (e.isIntersecting) { run(e.target); io.unobserve(e.target); }
  });
}, { threshold: .5 });

document.querySelectorAll('.count').forEach(el => io.observe(el));
</script>

  • Speed — change 1700
  • Suffix — data-suffix="+", "k", "%"

Code element

<style>

@keyframes blink{ 50%{opacity:0} }
h1{ min-height:1.3em }   /* stops the page jumping */

<script>
(async () => {
  const phrases = ['premium websites', 'sites that rank', '$10k builds'];
  const el = document.getElementById('typed');
  const wait = ms => new Promise(r => setTimeout(r, ms));
  let i = 0;

  while (true) {
    const word = phrases[i];
    for (let c = 0; c <= word.length; c++) {
      el.textContent = word.slice(0, c); await wait(85);
    }

  let timer = setInterval(() => go((i+1) % items.length), 6000);

  // swipe on touch
  let x0 = null;
  track.addEventListener('touchstart', e => {
    x0 = e.touches[0].clientX; clearInterval(timer);
  }, { passive: true });
  track.addEventListener('touchend', e => {
    if (x0 === null) return;
    const dx = e.changedTouches[0].clientX - x0;
    if (Math.abs(dx) > 50)
      go(dx < 0 ? (i+1) % items.length : (i-1+items.length) % items.length);
    x0 = null;
  });
})();
</script>

Customise

  • Autoplay speed — 6000, or delete that line to disable
  • Use full names, business names and specific outcomes. "Great service! — John" reads as invented

Text Scramble Reveal

AdvancedCode element
Live — decoding on a loop
WEB STUDIO

Where it goes

  1. Add a code element where the headline sits
  2. Paste below, edit the phrases list
Code element 
<h2 id="scramble">WEB STUDIO</h2>

<script>
(function(){
  const el = document.getElementById('scramble');
  const phrases = ['WEB STUDIO', 'PREMIUM SITES', '$10K BUILDS'];
  const chars = '!<>-_\\/[]{}—=+*^?#';
  let p = 0;

  function scramble(text){
    const old = el.textContent;
    const len = Math.max(old.length, text.length);
    let frame = 0;

    const queue = [];
    for (let i = 0; i < len; i++){
      queue.push({
        to: text[i] || '',
        start: Math.floor(Math.random() * 20),
        end:   Math.floor(Math.random() * 20) + 20
      });
    }

    (function tick(){
      let out = '', done = 0;
      queue.forEach((q, i) => {
        if (frame >= q.end){ done++; out += q.to; }
        else if (frame >= q.start){
          out += chars[Math.floor(Math.random() * chars.length)];
        } else { out += old[i] || ''; }
      });
      el.textContent = out;
      if (done < queue.length){ frame++; requestAnimationFrame(tick); }
    })();
  }

  setInterval(() => {
    p = (p + 1) % phrases.length;
    scramble(phrases[p]);
  }, 3000);
})();
</script>

Customise

  • Use a monospace font or the width jumps around as characters change
  • Speed — raise the 20 values for a slower decode
  • Strong for tech and agency brands. Wrong for a dentist

<script>
document.querySelectorAll('.magnetic').forEach(btn => {
  const strength = 0.35;   // how much it follows
  const radius   = 90;     // how close before it reacts

  addEventListener('mousemove', e => {
    const r  = btn.getBoundingClientRect();
    const cx = r.left + r.width  / 2;
    const cy = r.top  + r.height / 2;
    const dx = e.clientX - cx;
    const dy = e.clientY - cy;
    const dist = Math.hypot(dx, dy);

    if (dist < r.width / 2 + radius){
      btn.style.transform =
        `translate(${dx * strength}px, ${dy * strength}px)`;
    } else {
      btn.style.transform = 'translate(0,0)';
    }
  });
});
</script>
